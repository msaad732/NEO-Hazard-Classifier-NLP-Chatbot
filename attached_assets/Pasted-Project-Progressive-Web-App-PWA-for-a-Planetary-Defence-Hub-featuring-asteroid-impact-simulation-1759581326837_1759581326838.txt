Project: Progressive Web App (PWA) for a Planetary Defence Hub, featuring asteroid impact simulations, data visualization, and an AI-driven conversational core.

Target Aesthetic: Funky, Cool, Retro-Futuristic, Meteor Universe. The UI must feel like a vibrant, high-energy space command center from a '90s sci-fi film—professional but electric.

I. Core Theme, Color Palette, and Typography
A. Color Palette: Dark Mode / Neon Contrast
Background (The Void): Deep, inky black or very dark navy blue (e.g., #0A0A1F).

Primary Accent (Data/Glow): Electric Blue/Cyan (#00FFFF) – Used for active states, data points, and primary interface outlines.

Secondary Accent (Energy/Alert): Hot Magenta/Pink (#FF00FF) and Meteor Yellow/Orange (#FFD700) – Used for warnings, key CTAs, and secondary visualizations.

Contrast: Pure White (#FFFFFF) for main body text to ensure maximum readability against the dark background.

B. Typography: Sleek & Technical
Headlines/Titles: A bold, futuristic, highly stylized sans-serif font (e.g., Centauri or similar) that suggests advanced technology.

Body Text/Data: A clean, readable monospaced font (like Inconsolata or Space Mono) for data readouts, code snippets, and chat responses, maintaining the terminal/HUD aesthetic.

C. Background Atmosphere: Animated, Non-Obtrusive Universe 🌌
The entire background must feature subtle, continuous, low-contrast animation that runs on a low z-index.

Elements: Must include distant, twinkling stars (low-opacity particles), slowly moving celestial bodies (planets/nebulas/meteors), and very subtle parallax scrolling to create a sense of silent, massive scale.

Constraint (CRITICAL): The motion must be slow and the overall contrast of the background should be low to ensure it acts as ambient atmosphere rather than a visual distraction for the user's primary focus.

D. Readability Layer (The Planetary Hub Glass)
All on-screen content (text, charts, buttons, etc.) must be contained within a wrapper or container that is positioned above the animated background layer.

Styling: This layer must have a semi-transparent, dark overlay, achieved with rgba(0, 0, 0, 0.7) or similar. This creates the necessary high-contrast surface for the neon text to sit on top of, guaranteeing legibility while still letting the universe animation subtly show through.

Enhancement: Use backdrop-filter: blur(5px); on these content containers to achieve the desired Holographic/Glassmorphism effect, further softening the background details and making the text "pop."

II. Required Animations and Interactions (Non-Negotiable)
A. Custom Cursor Effect ☄️
Requirement: Replace the default browser cursor with a small, stylized icon of a comet or meteor (approx. 16x16px).

Interaction: As the user moves the cursor across the website, it must generate a continuous, fading particle trail (like a comet's tail) using the Electric Blue/Cyan accent color.

B. Custom Loading Button / Spinner 🔄
Target: All primary call-to-action (CTA) buttons that initiate a calculation, simulation, or AI request (e.g., "Run Prediction," "Generate Report," "Simulate Impact").

Animation: On click, the button text must be instantly replaced by a custom animated loading spinner: a stylized, rotating meteor with a flaming orange/yellow tail that spins rapidly while the process loads.

C. General UI Interactivity
Neon Pulse: All primary buttons and interactive inputs must exhibit a subtle, pulsating neon glow when hovered over or in focus.

Holographic Pop-up: Main data windows and modals should appear with a quick, translucent fade-in/scanline effect, as if being projected from a ship's console.

III. Component Styling and Layout
A. Data Visualization Panels (Chart.js Integrations)
Aesthetic: Panels displaying charts, graphs, and the USGS Map visualization must adopt the Heads-Up Display (HUD) / Glassmorphism look.

Styling: Must use the semi-transparent, blurred layer described in I.D., with sharply defined, glowing borders (Electric Blue/Cyan).

Charts: All chart lines, bars, and markers must use the vibrant neon accent colors. Gridlines on the charts should be faint, thin, and glowing, mirroring a targeting system.

B. AI Chatbot Interface (The Conversational Core)
Aesthetic: Resemble a classic computer terminal or console output, built on the layered aesthetic.

Container: The entire chat history and input box must sit within the semi-transparent, blurred content container (I.D.) for optimal readability.

AI Responses: Text generated by the AI should use the Electric Blue/Cyan accent color.

Animation: Implement a smooth, retro "typing" animation for the AI's responses.

User Input: The chat input field should feature a blinking cursor and a crisp, glowing border when active.

C. Navigation
Structure: A clean, minimal global header and/or persistent sidebar, also utilizing the semi-transparent overlay for visual consistency.

State: The currently active link must be highlighted with a solid, high-contrast glow using the primary accent color.

IV. Deliverables
1x Fully Designed Desktop Layout (e.g., the Simulation/Data Dashboard page) illustrating the layered background and content.

1x Fully Designed Mobile/PWA Layout (responsive version).

A Style Guide documenting the exact color codes, font choices, and animation specs for the custom cursor and loading spinner.
